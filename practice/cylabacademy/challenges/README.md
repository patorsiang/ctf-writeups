# CyLab Academy Challenges

Save new challenge writeups here by learning path:

```text
<learning-path>/<challenge-name>/
```

Each challenge folder should start with `README.md` from [../../../templates/cylabacademy-challenge-readme.md](../../../templates/cylabacademy-challenge-readme.md). Add `attachments/` and `output/` only when needed.

Do not duplicate legacy picoGym folders here. Link to [../../picogym](../../picogym) from the learning-path index when an older solve is still useful.
